# Starfood

Сайт доставки продуктов и рецептов. React + TypeScript + Vite + React Router.
Макет — колонка шириной 430px по центру: на телефоне занимает весь экран, на ПК выглядит так же.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173 (доступен и с телефона по IP в локальной сети)
npm run build     # продакшн-сборка в dist/
npm run preview
```

## Структура

- `src/data.ts` — категории, рецепты, слайды промо (тут же поле `image` для реальных фото)
- `src/store.tsx` — корзина и избранное (сохраняются в localStorage)
- `src/pages/` — Главная, Каталог, Рецепты, Корзина, Профиль
- `src/components/` — шапка, нижнее меню, карточки, карусель
- `src/styles.css` — все стили

## Фото

Сейчас вместо фото используются эмодзи на градиентах. Чтобы подставить настоящие фото, положите
файлы в `public/img/` и укажите путь в `src/data.ts`, например `image: "/img/carbonara.jpg"`.
