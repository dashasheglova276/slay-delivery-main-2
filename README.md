# StarFood

Сайт доставки продуктов и готовой еды. Интерфейс магазина работает на Next.js, а каталог, аккаунты, заказы и кабинеты сотрудников используют общую базу PostgreSQL через Prisma.

## Разделы

- Магазин: главная, каталог, категории и подборки, поиск, карточки товаров, рецепты, избранное и корзина.
- Оформление заказа: данные покупателя, адрес и время доставки, оплата, отслеживание статуса.
- Личный кабинет: заказы, повтор покупки, адреса, бонусы и настройки.
- Кабинет курьера: назначенные заказы и смена этапов доставки.
- Админ-панель: товары, категории, подборки, рецепты, сотрудники, цены и статусы заказов.

## Локальный запуск

1. Установите зависимости: `npm install`.
2. Создайте `.env` по образцу `.env.example` и настройте `DATABASE_URL`.
3. Запустите PostgreSQL, примените миграции командой `npm run db:migrate` и заполните демонстрационные данные командой `npm run db:seed`.
4. Запустите сайт: `npm run dev`.

Откройте `http://localhost:3000`. Админ-панель находится по адресу `/admin`, кабинет курьера — `/courier`.

Для production-сборки используйте `npm run build`, затем `npm run start`. Для карты при оформлении заказа задайте ключи Яндекс Карт из `.env.example`.
